# Project Rules & Workflow Instructions

## Auto-Push to Git
- Whenever any change, update, or bug fix is made to the codebase in this project, **always immediately** stage, commit, and push the code to GitHub (origin main):
  1. git add .
  2. git commit -m "<concise descriptive message>"
  3. git push origin main
- Never wait for the user to explicitly ask to push to GitHub.
